# Changelog

## 0.1.0

- First release.
- Zwift Click v2 (left and right unit) over BLE with the RideOn handshake.
- Key backends: hyprland, wtype, xdotool, uinput.
- Key map from a TOML file and `--map` flags. MyWhoosh map is the default.
- Test mode, one key per press, reconnect after sleep, RESET and LOCKED handling.
